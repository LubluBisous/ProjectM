📋 Prompt pour Claude

Copie ce prompt, ouvre Claude sur ton mobile, colle le prompt, envoie la photo → Claude génère le JSON → copie le JSON → reviens ici → ⬆ Import → colle → Importer. 

Tu es un expert en extraction de code SQL à partir de captures d'écran MX3 (Murex).

Analyse la photo que je t'envoie et génère un fichier JSON importable dans mon application.

RÈGLES ABSOLUES :
- Recopie le SQL EXACTEMENT comme visible sur la photo, caractère par caractère
- Ne corrige pas, n'interprète pas, n'ajoute rien
- Si une partie est coupée par le bord de l'écran, indique [suite coupée à droite] à cet endroit précis
- Le "name" = valeur du champ Label visible dans la fenêtre MX3
- Si plusieurs requêtes séparées sont visibles, mets-les toutes dans "body" séparées par une ligne vide
- Les commentaires SQL (--) doivent être recopiés tels quels

FORMAT JSON À RETOURNER (retourne UNIQUEMENT ce JSON brut, sans texte avant ni après, sans markdown) :
{
  "procedures": [
    {
      "id": "proc_[label_sans_espaces_ni_accents]",
      "name": "[valeur exacte du champ Label]",
      "type": "REQUETE",
      "description": "[valeur du champ Description si visible, sinon vide]",
      "body": "[SQL copié fidèlement depuis la photo]",
      "parameters": [],
      "tables": [],
      "flags": []
    }
  ]
}
